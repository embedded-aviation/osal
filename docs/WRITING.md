# Writing Standard

All English text in this repository must obey ASD-STE100, Simplified
Technical English (STE). The ASD-STE100 specification is the authority.

This rule applies to code comments, Doxygen text, README files, the files in
`docs/`, log messages, test names and messages, and commit messages.
Identifiers are not text; `docs/FORMATTING.md` controls them.

The rules that apply most frequently:

1. Use only the words in the STE dictionary, with their approved meaning. Use
   one word for one meaning. You can use technical names and technical verbs.
2. A procedural sentence has a maximum of 20 words. A descriptive sentence has
   a maximum of 25 words.
3. Write one instruction in one sentence. Use the imperative for instructions.
4. Use the active voice and the simple tenses (present, past and future).
5. Do not use phrasal verbs, idioms or noun clusters of more than three words.
6. Write about one topic in one paragraph, with a maximum of six sentences.
7. Use vertical lists for steps.

New text and changed text must obey this rule. When you change a file, make
the text near your change obey this rule too.

The zephyrus repository has the full summary of these rules in
`docs/CODING_STANDARDS.md`, rule `Z-021`.
